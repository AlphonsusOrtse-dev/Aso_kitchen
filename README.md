# Aso Kitchen

A digital menu, pre-ordering, and live order-tracking system for Aso
Kitchen.

This repository is organized by component:

- **[`aso-kitchen-backend/`](./aso-kitchen-backend)** — Go backend (API,
  database, authentication, real-time order tracking). See its
  [README](./aso-kitchen-backend/README.md) for full architecture,
  setup, and testing instructions.
- **Frontend** — not yet started.
